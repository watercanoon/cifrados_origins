Cifrado de Polybios

offline

El Cifrado de Polybios es un cifrado clásico de sustitución inventado en la antigua Grecia: cada letra se convierte en un par de coordenadas dentro de una cuadrícula 5×5.

Cuadrícula 5×5

Longitud 0
Pares 0
Ratio 2×

Parámetros

Operación

Alfabeto

Tipo de Coordenadas

¿Cómo funciona?

  1. Ingresa tu mensaje en Texto Original.
  2. Cada letra se sustituye por sus coordenadas (fila, columna) en la cuadrícula 5×5.
  3. El resultado aparecerá en Texto Cifrado como pares de dígitos.
  4. Para descifrar, introduce las coordenadas y se recuperará el texto original.
