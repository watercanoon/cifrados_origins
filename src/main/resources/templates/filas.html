Cifrado por Filas

offline

El Cifrado por Filas es un método clásico de transposición: el mensaje se organiza en una matriz y se lee por filas para generar el criptograma.

Parámetros

Ingresa caracteres únicos sin espacios.

3

La longitud define Nf. No debe contener letras repetidas.

Información de la Matriz

Filas (Nf): 3
Longitud de Texto (Lc): 0
Columnas de la Matriz (Nc): 0
Estado de Clave: VÁLIDA
Alfabeto Activo: ABCDEFGHIJKLMNÑOPQRSTUVWXYZ

¿Cómo funciona?

  1. Ingresa tu mensaje en Texto Original.
  2. El texto se organiza en una matriz con N filas.
  3. Se lee horizontalmente por filas para formar el criptograma.
  4. El resultado aparece en Texto Cifrado.
  5. Para descifrar, se coloca el criptograma en la matriz y se lee por columnas, recuperando el mensaje original.
